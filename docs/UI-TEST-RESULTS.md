# Kiểm thử giao diện Electron V1

Đạt: thiết lập Admin, mã khôi phục, đăng nhập/đăng xuất, nguồn tiền, đối tác, danh mục, thu/chi, sửa phiếu, hủy thao tác xóa, chuyển quỹ có phí, công nợ, tìm kiếm, lọc sheet Excel, nhật ký trước/sau và điều hướng tất cả phân hệ.

Đạt: ảnh bằng chứng khi tạo phiếu, phóng to, sửa chú thích/gỡ giữ bản gốc; lịch tiếng Việt, hai biểu đồ tròn và cột, bấm chú giải lọc chứng từ. Không có lỗi JavaScript trong các bước kiểm thử. Chụp giao diện ở 1450px và 1100px. Dữ liệu minh họa là dữ liệu kiểm thử riêng.
